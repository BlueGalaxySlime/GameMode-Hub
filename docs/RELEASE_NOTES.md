# SteamHub 0.3.0

Wydanie z modułem **Tab Manager** i integracją zakładek z biblioteką SteamOS.

- Zakładka **SteamHub** na pasku biblioteki SteamOS.
- Własne zakładki, zmiana nazw, kolejności, ukrywanie i usuwanie.
- Podstawowe filtry: wszystkie gry, zainstalowane, ulubione, spoza Steam, kolekcje Steam.
- Quick Tabs i profile zakładek.
- Przełącznik modułu domyślnie wyłączony.
- Ochrona przed równoczesnym użyciem TabMastera.
- Licencja GPL-3.0 i informacje o autorach TabMastera.

**Ważne:** funkcje Tab Managera nadal są eksperymentalne i nie zostały
zweryfikowane na rzeczywistym urządzeniu SteamOS. Nie jest to jeszcze
pełny odpowiednik TabMastera.

**Instalacja:** pobierz `SteamHub.zip` z sekcji Assets i zainstaluj
przez Decky Loader. Moduł włączasz przez SteamHub → Moduły → Tab Manager.
Jeśli TabMaster jest aktywny, wyłącz go przed uruchomieniem Tab Managera.

Wersja ma zwykły numer **0.3.0**, a nie prerelease, aby trafiła do
`/releases/latest` wykorzystywanego przez sprawdzanie aktualizacji.
