# SteamHub 0.3.0-preview.1 — Testowy Tab Manager

**Wersja przedpremierowa, do testów na SteamOS.** Funkcja zakładek nie została jeszcze
potwierdzona na prawdziwym urządzeniu. W razie problemu wróć do ostatniej stabilnej wersji.

- Oddzielny **Tab Manager**, domyślnie wyłączony.
- Eksperymentalna, rzeczywista zakładka **SteamHub** na pasku biblioteki SteamOS.
- Własne zakładki z filtrami: wszystkie, zainstalowane, ulubione, gry spoza Steam,
  kolekcje Steam.
- Dodawanie, zmiana nazwy, ukrywanie, duplikowanie i ustawianie kolejności.
- Quick Tabs: Zainstalowane, Ulubione.
- Profile zakładek: zapisz / wczytaj / usuń.
- Sprawdzanie aktywności TabMastera przez Decky, bez ingerowania w jego pliki.
- Zapis konfiguracji poza katalogiem wtyczki.
- Oznaczenia autorów TabMastera i licencja GPL-3.0.

**Jak sprawdzić:** zainstaluj ZIP z tego wydania przez Decky, wyłącz TabMaster
w Decky, włącz SteamHub → Moduły → Tab Manager, a następnie otwórz ponownie Bibliotekę.

To nie jest jeszcze kompletny odpowiednik TabMastera: zaawansowane filtry oraz
integracje znajomych/tagów i część opcji pozostają do wykonania.
